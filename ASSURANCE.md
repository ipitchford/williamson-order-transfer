# Assurance and trust boundaries

## What supports the result

- **Analytic argument:** the manuscript gives the row identity, repeated-tail
  contraction, finite tensor determination and continuous-model identification.
- **Exact finite evidence:** the supplied order-six certificate represents 197
  ordered coefficients. Checkers use rational arithmetic and inspect equations,
  ranks, root recursions and exact-flow targets.
- **Separately implemented checks:** the `code/independent` scripts do not import
  the generator. This describes implementation separation, not an external
  organisation's reproduction or human validation.
- **Negative controls:** corrupted certificate data must be rejected, and a
  reversed matrix-multiplication convention gives a lower-order defect.
- **Order-seven evidence:** `code/order7_criterion.py` enumerates all 115
  weight-seven families and checks the three unresolved directions. It supports
  a sufficient conditional criterion, not automatic seventh-order transfer.

## What is not established

There is no proof-assistant formalisation of this release, independent external
human review, performance benchmark, complete priority proof, prescribed-stage
existence theorem or unrestricted-order transfer theorem. The retained
`code/order7_boundary.json` is a stopping-boundary record, not a positive
seventh-order certificate.

AI-assisted reviews and revisions are bounded internal scrutiny. Successful
replay checks the stated finite objects; it does not independently establish
the universal analytic argument. Consult retained exact-version receipts rather
than treating this descriptive file as a successful execution receipt.
